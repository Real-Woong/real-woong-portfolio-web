## **📌 프로젝트 개요**

OpenCV와 Python 기반으로

**컴퓨터 비전 기술을 직접 구현하며 학습하기 위해 진행한 실험 프로젝트 모음입니다.**

단순히 라이브러리를 사용하는 수준을 넘어

- 손 제스처 인식
- 얼굴 감정 인식
- 실시간 영상 처리

등 **기본적인 CV 파이프라인을 직접 구현하면서 구조를 이해하는 것**을 목표로 진행했습니다.

이 프로젝트들은 완성된 서비스라기보다

> **Computer Vision 기술을 실험하고 학습하기 위한 개인 연구 프로젝트입니다.**
> 

현재도 새로운 기능을 추가하거나 모델을 교체하면서

지속적으로 실험을 이어가고 있습니다.

## **🧪 1️⃣ Hand Music Controller**

### **개요**

웹캠으로 손 제스처를 인식해

**음악 재생을 제어하는 인터랙티브 프로젝트**

OpenCV 기반 손 추적을 활용하여

- 손 제스처 인식
- 음악 플레이어 제어

를 연결하는 구조로 구현했습니다.

### **주요 구현**

- OpenCV 기반 **실시간 손 추적**
- 제스처 인식 로직 구현
- Python 기반 **음악 제어 시스템 연동**

### **학습 포인트**

- 실시간 영상 처리 구조
- 제스처 기반 인터랙션 설계
- CV 입력 → 프로그램 제어 로직 연결

[Git Hub]

[https://github.com/Real-Woong/hand-music-controller](https://github.com/Real-Woong/hand-music-controller)

## **✋ 2️⃣ Hand Gesture Recognition**

### **개요**

웹캠을 통해 손 모양을 인식하고

특정 제스처를 분류하는 **기초 제스처 인식 프로젝트**

다양한 손 모양 이미지를 활용하여

제스처 인식 로직을 구현했습니다.

### **주요 구현**

- OpenCV 기반 손 이미지 처리
- 제스처 이미지 기반 패턴 인식
- 간단한 제스처 분류 로직 구현

### **학습 포인트**

- 이미지 기반 특징 추출
- 기본적인 CV 기반 분류 로직 이해
- 데이터 기반 인식 시스템 구조 이해

[Git Hub]

[https://github.com/Real-Woong/hand-gesture-recognition](https://github.com/Real-Woong/hand-gesture-recognition)

## **🙂 3️⃣ Real-Time Facial Emotion Recognition**

### **개요**

웹캠을 통해 얼굴을 인식하고

**실시간 감정 인식(Emotion Recognition)** 을 수행하는 프로젝트입니다.

얼굴 검출 후 감정 분류 모델을 적용하여

영상 위에 감정 결과를 실시간으로 표시하도록 구현했습니다.

### **주요 구현**

- 얼굴 검출 (Face Detection)
- 실시간 감정 분류
- OpenCV 기반 영상 오버레이 출력

### **학습 포인트**

- Face detection 파이프라인 이해
- CV 모델을 실시간 영상 처리에 적용
- 결과 시각화 및 UI overlay 구현

[Git Hub]

[https://github.com/Real-Woong/realtime-emotion-recognition](https://github.com/Real-Woong/realtime-emotion-recognition)
