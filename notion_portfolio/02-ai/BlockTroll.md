# BlockTroll

프로젝트 성격: AI / ML 프로젝트
작업 영역: AI-Project, 개인-프로젝트
개발언어: python
브랜드: 개인-불편함해결

## **📌 프로젝트 개요**

유튜브·SNS 댓글 환경에서 발생하는

**욕설, 비꼼, 트롤링 등 악성 댓글 문제를 완화하기 위한 AI 기반 댓글 필터링 도구.**

브라우저 확장 프로그램 형태로 동작하며,

사용자가 댓글을 읽기 전에 **AI 모델이 댓글의 공격성·독성 여부를 판단**하여

자동으로 블러 처리하거나 숨김 처리할 수 있도록 설계하고 있습니다.

단순 욕설 필터링을 넘어

**비꼼, 조롱, 과도한 찬양(억빠/주접) 등 다양한 댓글 유형을 분류하는 AI 모델을 구축하는 것을 목표로 개발 중인 프로젝트입니다.**

---

## **🚧 현재 개발 상태**

현재 **AI 모델 학습 및 댓글 분류 시스템을 중심으로 개발 진행 중**이며,

- 댓글 데이터셋 구축 및 라벨링
- Transformer 기반 댓글 분류 모델 학습
- Chrome Extension 기반 댓글 필터링 기능 구현

을 단계적으로 개발하고 있습니다.

---

## **🧠 핵심 설계 포인트**

- **AI 기반 댓글 분류 시스템**
    - Transformer 기반 NLP 모델을 활용한 댓글 유형 분류
    - 욕설 / 비꼼 / 칭찬 / 과도한 찬양 등 다양한 댓글 카테고리 분류
- **브라우저 확장 프로그램 기반 실시간 필터링**
    - 페이지 로드 시 댓글을 자동 분석
    - 독성 댓글 블러 처리 또는 숨김 처리
- **로컬 모델 추론 구조**
    - 서버 API 없이 로컬 환경에서 댓글 분석 가능
    - 개인정보 및 사용자 활동 데이터 외부 전송 없음
- **확장 가능한 모델 구조**
    - Hugging Face 기반 모델 교체 및 추가 학습 가능
    - 데이터셋 확장에 따라 분류 카테고리 확장 가능

---

## **⚙️ 배운 점**

- NLP 모델 성능은 **모델 구조보다 데이터 품질과 라벨링 기준이 더 중요한 요소**라는 점을 경험
- 실제 서비스 환경에서는 **모델 정확도뿐 아니라 추론 속도와 리소스 사용량 최적화가 중요**함을 이해
- 브라우저 확장 프로그램과 AI 모델을 결합하면서
    
    **AI 기능을 실제 사용자 환경에 적용하는 시스템 구조를 설계하는 경험**을 얻음
