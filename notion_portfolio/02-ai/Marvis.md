# Marvis

# **📌 Marvis**

### **Telegram-based Personal AI Assistant**

아이디어를 자주 잊거나 일정 관리에 번거로움을 느끼는 사용자를 위해 만든

**텔레그램 기반 개인 AI 비서 프로젝트**입니다.

**Marvis**는 **My + Jarvis**의 합성어로,

사용자가 텔레그램에 자연어로 메시지를 보내면 내용을 기억하고

**메모·아이디어·할 일·일정으로 분류하여 관리**합니다.

Google Gemini를 활용해 저장된 기억을 바탕으로 답변하며,

텍스트와 함께 **한국어 음성 답변**도 제공하도록 설계했습니다.

현재는 Oracle Cloud 서버에서 지속적으로 실행되는

**개인용 AI 비서 프로토타입**을 중심으로 개발하고 있습니다.

---

# **🏗 현재 구현 상태**

### **Personal AI Assistant Prototype (운영 중)**

- Telegram Bot 기반 대화 인터페이스 구현
- Google Gemini 기반 AI 답변 생성
- 사용자 메시지 기억 및 자동 분류
- 일정 날짜와 시간 자동 인식
- 지정된 시간에 Telegram 알림 전송
- gTTS 기반 한국어 음성 답변 생성
- Oracle Cloud 서버 상시 실행 환경 구축
- systemd 기반 자동 시작 및 장애 재실행 구성

현재 단계에서는 **아이디어와 일정을 빠르게 기록하고 다시 찾는 개인 비서 경험을 검증하는 데 집중하고 있습니다.**

# **💡 핵심 기능**

### **1️⃣ 자연어 기반 기억 시스템**

사용자가 별도의 입력 형식을 배우지 않아도

텔레그램에서 평소처럼 메시지를 보내면 Marvis가 내용을 기억합니다.

저장된 내용은 메시지에 포함된 키워드와 날짜 정보를 기반으로

다음과 같이 자동 분류됩니다.

**Schedule — 일정 및 할 일**

- 날짜나 시간이 포함된 일정
- 해야 할 일, 약속, 회의, 마감 등
- 예: 내일 오후 3시에 병원 예약 확인해야 해

**Idea — 아이디어**

- 프로젝트, 서비스, 기능, 사업 아이디어
- 구현하거나 발전시키고 싶은 생각
- 예: 새로운 AI 서비스 아이디어가 생각났어

**Note — 일반 기억**

- 일정이나 아이디어로 분류되지 않는 일반 메모
- 나중에 다시 확인하고 싶은 생각이나 정보

이를 통해 사용자는 메모 앱을 직접 열거나 분류하지 않고도

**대화하듯 자신의 생각을 기록할 수 있습니다.**

---

### **2️⃣ 일정 및 리마인더 관리**

Marvis는 메시지에 포함된 날짜와 시간을 분석하여

일정과 알림 시간을 자동으로 저장합니다.

현재 지원하는 입력 방식은 다음과 같습니다.

- 오늘, 내일, 모레
- 2026-07-20, 7.20, 7월 20일
- 오전·오후 시간 표현
- 10분 뒤, 2시간 후와 같은 상대 시간
- 날짜와 시간이 함께 포함된 일정

예를 들어

**“오늘 오후 8시에 운동하라고 알려줘”**

라고 입력하면 해당 내용을 일정으로 저장하고,

시간이 되면 Marvis가 먼저 텔레그램 메시지를 전송합니다.

---

### **3️⃣ 저장된 기억 기반 AI 답변**

Marvis는 단순히 Gemini의 답변을 전달하는 챗봇이 아니라

사용자의 저장된 기억을 AI 문맥에 함께 제공합니다.

이를 통해 다음과 같은 질문에 답할 수 있습니다.

- 오늘 내가 해야 할 일이 뭐야?
- 내가 전에 말한 아이디어가 뭐였지?
- 남아 있는 일정 정리해줘
- 지금 가장 먼저 해야 할 일을 알려줘

AI는 현재 일정, 최근 기억, 최근 아이디어를 참고하여

**사용자 개인의 상황에 맞는 답변과 우선순위**를 제공합니다.

---

### **4️⃣ 텍스트·음성 동시 응답**

Gemini가 생성한 답변은 텔레그램 텍스트 메시지와 함께

**한국어 MP3 음성 파일**로도 전달됩니다.

이를 통해 사용자는 화면을 계속 확인하기 어려운 상황에서도

에어팟이나 이어폰을 통해 Marvis의 답변을 들을 수 있습니다.

특히 이동 중에도 쉽게 이해할 수 있도록

**핵심부터 짧고 명확하게 답변하는 방식**을 적용했습니다.

---

### **5️⃣ Telegram 명령어 시스템**

저장된 정보를 빠르게 조회하고 관리할 수 있도록

다음 명령어를 제공합니다.

- `/memory` — 최근 저장된 기억 확인
- `/schedule` — 날짜별 일정 및 할 일 확인
- `/ideas` — 최근 저장된 아이디어 확인
- `/done 번호` — 선택한 항목 완료 처리
- `!스케쥴` — 날짜별 일정 빠른 확인
- `/forget_all_marvis` — 전체 기억 삭제

---

### **6️⃣ 자동 메모리 최적화**

기억 데이터가 계속 쌓여도 안정적으로 사용할 수 있도록

자동 정리 구조를 적용했습니다.

- 지난 날짜의 일정 자동 정리
- 완료된 일정 상태 관리
- 오래된 일반 메모 우선 정리
- 아이디어 및 전체 기억 개수 제한
- 저장 항목 번호 자동 재정렬
- 이미 전송한 알림의 중복 발송 방지

현재 기억 데이터는 별도의 데이터베이스 없이

**JSON 파일 기반으로 저장 및 관리**됩니다.

# **🧠 프로젝트에서 중요하게 생각한 점**

이 프로젝트는 단순히 질문에 답하는 챗봇이 아니라

- *“AI가 사용자의 생각과 일정을 대신 기억해줄 수 있는가”**에 대한 실험입니다.

특히 다음을 중심으로 설계했습니다.

- 별도의 작성 형식 없이 **대화만으로 기록하는 구조**
- 사용자의 메시지를 **일정·아이디어·메모로 자동 분류**
- 저장된 기억을 활용하여 **개인화된 답변 제공**
- 요청을 기다리는 것뿐만 아니라 **필요한 시간에 먼저 알림**
- 이동 중에도 사용할 수 있는 **텍스트·음성 동시 응답**
- 복잡한 생산성 도구보다 빠르고 가벼운 **Telegram 중심 인터페이스**

Marvis의 목표는 사용자가 모든 것을 직접 기억하고 관리하지 않아도

필요한 순간에 자신의 생각과 일정을 다시 꺼낼 수 있도록 돕는 것입니다.
