## 정리 기준

- 원본 `notion_info` 폴더는 변경하지 않음
- 파일명의 Notion 식별용 해시 제거
- 이미지 및 이미지 삽입 문법 제외
- 빈 템플릿과 화면 캡처 설명 전용 문서 제외
- CSV에만 있던 분류 정보는 폴더 구조에 반영

## 웹사이트 적용 시 확인할 항목

- 프로젝트별 기간과 진행 상태 표기 통일
- `CyptoFunding`의 표기가 의도된 것인지 확인
- 일부 프로젝트의 기술 스택과 본문 내용 불일치 검토
- GitHub, 영상, 배포 링크의 공개 여부와 유효성 확인
- 금융 관련 프로젝트는 PAPER Trading 및 비투자 권유 문구 유지
