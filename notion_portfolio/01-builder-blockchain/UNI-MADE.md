# UNI-MADE

작업 영역: 창업-프로젝트, 팀-프로젝트
브랜드: ＵＭＣ 프로젝트
개발언어: JS
역할: FE

## **📌 프로젝트 개요**

대학생 셀러가 상품을 등록·판매할 수 있는 온라인 플랫폼.

서비스 단위 웹 애플리케이션을

팀 기반으로 구현한 첫 React 프로젝트입니다.

---

## **💡 담당 영역**

- MyPage, SellerPage 구현
- 상품 등록 / 수정 / 상세 확인 기능
- 회원정보 수정 기능 구현
- Figma 기반 디자인 일부 보조

---

## **🧠 배운 점**

- 컴포넌트 단위 설계
- TanStack Query 기반 서버 상태 관리
- CRUD 흐름 설계
- PR 기반 협업 및 Git 심화 경험

> “단순 React 학습을 넘어, 실제 서비스 구조를 경험한 프로젝트”
>
