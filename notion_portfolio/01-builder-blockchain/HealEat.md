# HealEat

작업 영역: 창업-프로젝트, 팀-프로젝트
브랜드: ＵＭＣ 프로젝트
개발언어: swift
역할: FE (iOS)


## **📌 프로젝트 개요**

건강 정보를 기반으로 외식 가능한 매장을 추천하는 iOS 앱.

팀 기반 협업 구조에서 MVVM과 Reactive Programming을

처음으로 실전 적용한 프로젝트입니다.

---

## **💡 내가 맡은 부분**

- 로그인 화면 및 건강 정보 설정 UI 구현
- Moya 기반 API 연동
- RxSwift 기반 데이터 바인딩
- Auth 브랜치 독립 작업 및 협업

---

## **🧠 이 프로젝트의 의미**

- MVVM 아키텍처를 실제 코드에 적용
- Reactive Programming 개념 체득
- Git 브랜치 전략 기반 협업 경험
- 대규모 팀 프로젝트 구조 이해

> “앱 개발을 ‘기능 구현’에서 ‘구조 설계’ 관점으로 보기 시작한 첫 프로젝트”
>
