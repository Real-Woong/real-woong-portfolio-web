# Sogon.zip

# **📌 Sogon.zip**

### **마음은 예약하고, 데이트는 함께**

연인이나 가까운 친구가 서로의 **취향, 마음, 작은 비밀**을 안전하게 저장하고,

정해둔 순간에 함께 열어볼 수 있도록 만든

**관계 기반 프라이빗 아카이브 서비스**입니다.

사용자는 상대에게 언젠가 전하고 싶은 내용을 **소곤파일(Sogon File)**로 저장하고,

공개 시점과 추천 반영 여부를 직접 결정할 수 있습니다.

공개 전의 내용은 상대에게 보이지 않으며,

예약한 날짜가 되어도 자동 공개되지 않고 작성자가 마지막으로 확인한 뒤 직접 압축해제합니다.

Sogon.zip은 새로운 사람을 찾는 데이팅 앱이 아니라,

**이미 가까운 두 사람이 서로를 더 안전하고 다정하게 알아가기 위한 관계 도구**입니다.

# **💡 핵심 기능**

### **1️⃣ 소곤파일 — 마음을 프라이빗 파일로 저장**

사용자는 상대에게 언젠가 알려주고 싶은 취향이나 마음을

일반 메모가 아닌 **공개 규칙을 가진 파일**로 저장합니다.

파일에는 다음 정보를 설정할 수 있습니다.

- 관심사 및 내용 태그
- 상대에게 전하고 싶은 내용
- 민감도
- 파일이 열릴 시점
- 데이트 추천 반영 여부

추천 반영과 상대 공개는 서로 다른 개념입니다.

추천 반영을 허용하더라도 파일 원문은 열기 전까지 상대에게 전달되지 않습니다.

---

### **2️⃣ 예약 공개와 작성자 중심 압축해제**

소곤파일은 현재 상태에 따라 네 가지 폴더로 구분됩니다.

- **열릴 예정** — 기념일이나 특정 날짜까지 비공개로 보관
- **열 준비됨** — 예약 시점이 지났지만 아직 작성자가 공개하지 않은 상태
- **열림** — 작성자가 최종 확인 후 상대에게 공개한 상태
- **닫아둠** — 공개하지 않고 계속 보관하는 상태

`100일 후`, `1년 후`, 직접 날짜 선택 등의 옵션을 실제 ISO 시각으로 저장하고,

정해둔 시간이 지나면 파일을 `열 준비됨` 상태로 전환합니다.

단, 시간이 되었다는 이유만으로 내용이 자동 공개되지는 않습니다.

**최종 공개 결정권은 항상 작성자에게 있습니다.**

---

### **3️⃣ 계정 코드 기반 1:1 관계 연결**

회원가입을 완료하면 사용자마다 고유한 계정 코드가 발급됩니다.

상대의 코드를 입력하면 계정을 확인하고 연결 요청을 보낼 수 있으며,

상대가 직접 수락해야 두 사람이 사용하는 공유 소곤폴더가 만들어집니다.

- 코드를 아는 것만으로 즉시 연결되지 않음
- 한 공유 공간의 정원을 두 명으로 제한
- 동일 상대에게 중복 연결 요청 방지
- 연결 전에는 상대의 파일에 접근할 수 없음
- 연결 후에도 상대가 직접 연 파일만 조회 가능

불특정 다수를 연결하는 매칭보다

**이미 알고 있는 한 사람과의 안전한 연결**에 초점을 맞췄습니다.

---

### **4️⃣ 두 가지 핵심 경험을 분리한 홈**

홈 화면에서는 Sogon.zip의 두 가지 기능을 시각적으로 분리했습니다.

#### **SOGON DELIVERY**

기념일이나 특별한 날짜에 맞춰 마음을 저장하고 전달하는 영역입니다.

예약된 파일 수와 열 준비가 된 파일 수를 확인하고 새 소곤파일을 만들 수 있습니다.

#### **DATE MATCH**

두 사람이 각자 저장한 음식·활동·분위기·예산 취향을 바탕으로

함께 만족할 데이트 코스를 고르는 영역입니다.

아직 연결된 상대가 없다면 홈 최상단에서 연결 상태와

**“연결 코드 입력하기”** 행동을 바로 안내합니다.

---

### **5️⃣ 취향 기반 데이트 코스 추천 설계**

추천 시스템은 한 사람에게만 인기 있는 장소가 아니라,

**두 사람 중 낮은 쪽 만족도를 우선 보호하는 공동 추천**을 목표로 합니다.

추천 입력으로 사용할 정보는 다음과 같습니다.

- 음식, 활동, 분위기, 예산, 이동 선호
- 알레르기, 접근성, 절대 비선호 같은 강한 제한
- 날짜, 시작 지역, 교통수단, 이용 가능 시간
- 저장·건너뛰기·방문·만족도 피드백

추천 과정은 다음 순서로 설계했습니다.

1. 알레르기, 영업시간, 예산, 거리처럼 반드시 지켜야 할 조건으로 후보 제외
2. 두 사람 각각의 취향 일치도 계산
3. 한쪽에 치우치지 않도록 공동 만족도 산출
4. 이동시간을 고려해 2~3개 장소를 하나의 코스로 조합
5. 비슷한 장소가 반복되지 않도록 다양성 재정렬
6. 민감한 원문을 노출하지 않는 추천 이유 생성

장소 데이터는 카카오 로컬 API, 한국관광공사 TourAPI,

서울시 문화행사 OpenAPI 등의 연동을 검토하고 있습니다.

브랜드 팝업스토어는 통합 공개 API가 부족하므로

출처·행사 기간·마지막 확인 시각을 저장하는 자체 큐레이션 데이터 구조를 계획했습니다.

LLM은 자유 문장에서 취향 태그를 제안하고 설명 문구를 만드는 데만 사용하고,

알레르기·영업시간·예산 같은 필수 조건 판정은 규칙 기반 로직이 담당하도록 설계했습니다.

### **6️⃣ 나의 소곤폴더와 관계 기록**

작성한 소곤파일은 파일 아카이브 형태로 관리합니다.

- 상태별 파일 조회
- 기존 파일 수정 및 삭제
- 열 수 있는 파일 확인
- 작성자 최종 압축해제
- 상대가 공개한 파일 확인
- 공개된 순간을 기록 캘린더에서 탐색

`.zip`, 폴더, 파일, 잠금, 압축해제라는 은유를

기능 전반에 일관되게 적용했습니다.

# **🔐 프라이버시와 안정성**

관계 데이터와 비공개 내용을 다루는 서비스이므로

기능 구현만큼 **보이지 않아야 할 정보가 보이지 않는 것**을 중요하게 다뤘습니다.

- 비밀번호를 사용자별 16바이트 salt와 PBKDF2-SHA256으로 해싱
- 기존 SHA-256 계정은 로그인 성공 시 새 방식으로 자동 마이그레이션
- 32바이트 랜덤 세션 토큰을 발급하고 DB에는 SHA-256 해시만 저장
- 30일 세션 만료와 사용 중 슬라이딩 연장
- 15분 동안 로그인 10회 실패 시 일시 잠금
- 상대에게는 작성자가 `opened`로 전환한 파일만 반환
- 파일 수정·삭제·압축해제는 작성자 본인만 가능
- 연결 해제 시 계정을 지우지 않고 공유 공간과 관계 데이터만 안전하게 정리

프라이버시 사고로 이어질 수 있는 핵심 규칙은 자동 회귀 테스트로 고정했습니다.

- 공개 전 파일 가시성
- 공유 공간 최대 인원
- 예약 날짜의 실제 상태 전환
- 비밀번호 해싱과 기존 계정 마이그레이션
- 작성자 권한과 안전한 관계 해제

# **🧩 해결한 기술적 문제**

### **공개 페이지와 API 응답이 섞이는 문제**

Cloudflare Pages의 SPA fallback은 존재하지 않는 `/api/*` 요청에도

`index.html`을 200 응답으로 반환할 수 있습니다.

이 응답을 정상 API 결과로 오인하면 인증되지 않은 사용자가 보호 화면에 진입할 위험이 있어,

클라이언트에서 응답의 `content-type`과 프로필 데이터 형태를 함께 검증하도록 만들었습니다.

### **관계 해제 시 계정까지 삭제될 수 있는 문제**

초기 D1 외래 키 구조에서 공유 방을 먼저 삭제하면

연결된 사용자 계정까지 `ON DELETE CASCADE`로 삭제될 수 있었습니다.

사용자를 방에서 먼저 분리한 뒤 공유 데이터와 방을 제거하는

`dissolveRoom()` 순서를 별도로 구현하고 회귀 테스트로 보호했습니다.

### **화면마다 달라질 수 있는 예약 규칙**

예약 옵션과 상태 계산을 프론트엔드와 백엔드에서 따로 관리하면

같은 파일이 화면마다 다른 상태로 보일 수 있습니다.

공유 도메인 모듈 `shared/sogonOpening.ts`를 단일 기준으로 두어

옵션 라벨, 예약 시각 계산, 열기 가능 여부를 통일했습니다.

# **🧠 프로젝트에서 중요하게 생각한 점**

이 프로젝트는 단순히 기록을 저장하는 서비스가 아니라,

**“가까운 사람에게 내 취향과 마음을 안전하게 전하려면 어떤 경험이 필요한가?”**

에 대한 실험입니다.

특히 다음 원칙을 제품과 코드에 함께 반영했습니다.

- 날짜가 되어도 자동 공개하지 않고 마지막 결정권을 작성자에게 제공
- 공개 전 원문을 보여주지 않으면서 허용된 취향만 추천에 활용
- 계정 코드를 아는 것과 관계 연결을 분리하고 상대의 명시적 수락 요구
- 두 사람의 평균뿐 아니라 낮은 쪽 만족도를 보호하는 추천
- 감성적인 파일 은유와 명확한 기능 구조의 균형
- 프라이버시 규칙을 문서가 아닌 자동 테스트로 검증

Sogon.zip은 관계를 새로 만드는 앱이 아니라,

**이미 소중한 관계를 더 깊고 다정하게 이어주는 앱**을 목표로 합니다.
