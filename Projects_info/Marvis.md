# Marvis

# **📌 Marvis**

### **Telegram 기반 개인 AI 비서**

아이디어를 자주 잊거나 일정 관리에 번거로움을 느끼는 사용자를 위해 만든

**텔레그램 기반 개인 AI 비서 프로젝트**입니다.

**Marvis**는 **My + Jarvis**의 합성어로,

사용자가 텔레그램(또는 iPhone Siri 단축어)으로 자연어 메시지를 보내면 내용을 기억하고

**메모·아이디어·할 일·일정으로 분류하여 관리**합니다.

Google Gemini를 활용해 저장된 기억을 바탕으로 답변하며,

텍스트와 함께 **한국어 음성 답변**도 제공하도록 설계했습니다.

Oracle Cloud 서버에서 24시간 상시 운영 중이며,

실제로 매일 사용하면서 발견한 문제(레이스 컨디션, 진입 장벽으로 인한 저사용 등)를

직접 고쳐 나가고 있는 **살아있는 개인용 프로덕트**입니다.

---

# **🏗 현재 구현 상태**

### **Personal AI Assistant (운영 중)**

- Telegram Bot 기반 대화 인터페이스
- Google Gemini 기반 AI 답변 생성
- 사용자 메시지 자동 기억 및 분류
- 일정 날짜·시간 자동 인식 및 능동 알림
- **매일 아침 8시, 요청 없이 먼저 오늘 일정을 브리핑**
- **iPhone Siri 단축어로 손 안 대고 음성 캡처** (Cloudflare Tunnel 경유)
- gTTS 기반 한국어 음성 답변 생성
- Oracle Cloud 서버 상시 실행 + systemd 자동 재시작
- 백그라운드 스레드 간 **레이스 컨디션 제거** (파일 락 + 원자적 쓰기)

현재 단계에서는 **"기록의 진입 장벽을 없애는 것"에 집중하고 있습니다.**

기능을 추가하는 것보다, 실제로 매일 손이 가게 만드는 것이 더 어려운 문제라는 걸

직접 사용하면서 깨달았고, 그 문제를 해결하는 방향으로 계속 개선 중입니다.

# **💡 핵심 기능**

### **1️⃣ 자연어 기반 기억 시스템**

사용자가 별도의 입력 형식을 배우지 않아도

텔레그램에서 평소처럼 메시지를 보내면 Marvis가 내용을 기억합니다.

저장된 내용은 메시지에 포함된 키워드와 날짜 정보를 기반으로 자동 분류됩니다.

- **Schedule** — 날짜·시간이 포함된 일정, 할 일, 약속, 마감
- **Idea** — 프로젝트·서비스·기능 아이디어
- **Note** — 일정·아이디어로 분류되지 않는 일반 메모

---

### **2️⃣ 일정 및 리마인더 관리**

메시지에 포함된 날짜·시간 표현(오늘/내일/모레, `7.20`, `7월 20일`, 오전·오후, `10분 뒤` 등)을

정규식 기반으로 분석해 일정과 알림 시각을 자동 저장하고, 시간이 되면 Marvis가 먼저 알림을 보냅니다.

---

### **3️⃣ 능동적 아침 브리핑**

사용자가 묻기 전에 Marvis가 먼저 말을 겁니다.

매일 아침 8시(KST), 그날 저장된 일정을 우선순위 순으로 정리해

**"오늘 할 일은 이거다"** 형태로 먼저 브리핑하는 기능을 추가했습니다.

리액티브 챗봇에서 벗어나, 사용자가 스스로 열어보지 않아도

필요한 정보가 알아서 도착하는 경험을 목표로 설계했습니다.

---

### **4️⃣ Siri 단축어 기반 무마찰 음성 캡처**

"앱을 열고 타이핑해야 기록한다"는 진입 장벽을 없애기 위해,

iPhone Siri 단축어로 말만 하면 바로 저장되는 경로를 추가했습니다.

- **"헤이 시리 → 받아쓰기"**로 캡처한 텍스트를
- 서버에 상주하는 경량 웹훅(`http.server` 기반, 외부 의존성 없음)으로 전송
- Cloudflare Tunnel로 오라클 서버 방화벽/포트 개방 없이 안전하게 노출 (비밀키 인증)
- 텔레그램 메시지와 **동일한 분류·저장·응답 파이프라인**을 그대로 통과

집처럼 폰을 잘 안 만지는 환경에서도, 손 안 대고 말만으로 기록할 수 있도록 만든 기능입니다.

---

### **5️⃣ 저장된 기억 기반 AI 답변**

Marvis는 단순히 Gemini의 답변을 전달하는 챗봇이 아니라

사용자의 저장된 기억(현재 일정, 최근 메모, 최근 아이디어)을 AI 문맥에 함께 제공합니다.

이를 통해 "오늘 뭐 해야 해?", "전에 말한 아이디어가 뭐였지?" 같은 질문에

**개인의 상황에 맞는 답변과 우선순위**를 제공합니다.

---

### **6️⃣ 텍스트·음성 동시 응답**

Gemini가 생성한 답변은 텔레그램 텍스트 메시지와 함께

**한국어 MP3 음성 파일**로도 전달되어, 화면을 보기 어려운 상황에서도 청취할 수 있습니다.

---

### **7️⃣ 안정성 — 레이스 컨디션 제거**

일정 알림을 감시하는 백그라운드 스레드와 텔레그램 메시지 핸들러가

같은 JSON 파일을 동시에 읽고 쓰는 구조에서 발생할 수 있는 **lost update / 파일 손상 문제**를

공유 락(`RLock`)과 **임시 파일 → 원자적 rename** 쓰기 방식으로 해결했습니다.

네트워크 전송(텔레그램 API 호출)은 락 밖에서 수행해, 알림 발송 중에도

다른 메시지 처리가 지연되지 않도록 설계했습니다.

---

### **8️⃣ Telegram 명령어 시스템**

- `/memory` — 최근 저장된 기억 확인
- `/schedule` — 날짜별 일정 및 할 일 확인
- `/ideas` — 최근 저장된 아이디어 확인
- `/done 번호` — 선택한 항목 완료 처리
- `!스케쥴` — 날짜별 일정 빠른 확인
- `/forget_all_marvis` — 전체 기억 삭제

---

### **9️⃣ 자동 메모리 최적화**

- 지난 날짜 일정 자동 정리
- 완료된 일정 상태 관리
- 오래된 일반 메모 우선 정리
- 아이디어/전체 기억 개수 제한 및 번호 자동 재정렬
- 중복 알림 방지

기억 데이터는 별도 데이터베이스 없이 **JSON 파일 기반**으로 저장·관리됩니다.

# **🧠 프로젝트에서 중요하게 생각한 점**

이 프로젝트는 단순히 질문에 답하는 챗봇이 아니라

**"AI가 사용자의 생각과 일정을 대신 기억해줄 수 있는가"**,

더 나아가 **"실제로 매일 쓰게 만들 수 있는가"**에 대한 실험입니다.

기능을 만드는 것과, 그 기능을 실제로 계속 쓰게 만드는 것은 다른 문제였습니다.

직접 사용하면서 "앱을 여는 것 자체가 귀찮아서 결국 안 쓰게 된다"는 걸 확인했고,

이후에는 새 기능 추가보다 **진입 장벽을 낮추는 방향**(능동적 브리핑, 음성 무마찰 캡처)에

우선순위를 두고 개선했습니다.

또한 개인 데이터가 담긴 파일이 아무 보호 장치 없이 버전 관리에 올라가 있던 문제,

백그라운드 스레드 간 파일 경쟁으로 데이터가 유실될 수 있던 문제 등

**실제 운영 중인 서비스에서만 드러나는 문제들을 직접 찾아 고치는 경험**을 쌓고 있습니다.
